# FORMA 演示短视频分镜脚本（60–90 秒）

> 求职演示用。主题：从「3D 展示器」到「AI 3D 资产管线」的完整闭环。
> 录制建议：1080p / 30fps，全程录屏 + 关键步骤特写。

## 分镜

| # | 时长 | 画面 | 旁白要点 |
|---|---|---|---|
| 1 | 0–8s | 展厅首页，五个琼剧手办卡片 + 生角旋转 | 「FORMA，一个琼剧数字手办展厅，也是 AI 3D 资产处理平台。」 |
| 2 | 8–16s | 点顶栏「管线」，进入工作模式 | 「顶部一键切换到 AI 管线工作模式。」 |
| 3 | 16–26s | 点「连接后端」，状态灯变绿，资产下拉出现 | 「本地后端仅监听本机，分析、AI、处理全部在本地完成。」 |
| 4 | 26–38s | 选「生角」→ 点「运行 AI 分析」，逐轮日志流 | 「AI Agent 用真实工具调用读取分析报告、提出建议——不是规则判断。」 |
| 5 | 38–50s | 勾选 weld + 生成法线 + 修复材质，出现 ⚠ 风险标记 | 「会改变外观的算子有风险标记，必须经过确认门。」 |
| 6 | 50–62s | 点「执行处理」→ 弹出确认 → 再次点击执行 | 「确认门：未确认不写盘，确认后真实执行。」 |
| 7 | 62–74s | Before/After 滑条左右拖动，法线/材质变化 | 「同场景滑动对比处理前后——加了法线、修正了金属度。」 |
| 8 | 74–85s | 点「加入展厅」，资产库组出现 ★ 新条目 | 「处理结果一键发布，回到展厅即可查看。」 |
| 9 | 85–90s | 结尾：五手办批量结果表 + 后验全通过 | 「五个手办批量处理、后验全通过，原始素材零改动。」 |

## 需要准备的特写素材

- 分析报告 JSON 特写（`report.before.json` vs `report.after.json`）
- 后验结果 `verify.json`（`pass: true` 逐项检查）
- 5 手办批量结果表（`docs/demo/batch-results.md`）

## 录制环境

```bash
npm run pipeline:serve   # 后端
node serve.mjs           # 前端（含 /api 反代）
# 浏览器 http://127.0.0.1:5173
```
